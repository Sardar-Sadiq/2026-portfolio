# Sardar Sadiq Portfolio 2026

A premium, high-performance portfolio website built with modern web technologies, featuring advanced animations, interactive components, and a sleek dark aesthetic.

## 🚀 Technologies

- **Core**: React 19 + Vite 7
- **Styling**: Tailwind CSS 4
- **Animations**: 
  - [Motion](https://motion.dev/) (formerly Framer Motion)
  - [GSAP](https://gsap.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Runtime/Package Manager**: [Bun](https://bun.sh/)
- **Effects**: 
  - Canvas Confetti
  - Custom ASCII Fire Animation

## ✨ Key Features

- **Interactive Stack Trace**: A unique, developer-centric work experience section that mimics a debugger interface.
- **ASCII Fire Footer**: A retro-modern fire animation combined with high-end glassmorphism.
- **Dynamic Stickers**: Custom-built GSAP-powered fire stickers and responsive image overlays.
- **Premium Glassmorphism**: Custom liquid glass cards with real-time blur and saturation effects.
- **Vercel Optimized**: Pre-configured `vercel.json` for high-performance deployment using Bun.

## 🛠️ Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (Recommended) or Node.js

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sardar-Sadiq/2026-portfolio.git
   ```

2. Install dependencies:
   ```bash
   bun install
   ```

3. Start the development server:
   ```bash
   bun run dev
   ```

## 📦 Building for Production

To create an optimized production build:

```bash
bun run build
```

## 🎨 Design Philosophy

The portfolio focuses on "precision-crafting digital experiences." It utilizes a dark mode base (`zinc-950`) with vibrant accents (`emerald-500`, `white/10`) and curated typography:  
- **Poppins**: For clean, readable UI text.
- **Caveat/Kalam**: For handwritten, personal touches.
- **Monospace**: For technical details and code-like elements.
